# Show do Jorjão — formato de perguntas

Foi adicionado à configuração inicial o seletor **Formato da partida**:

- **Mesma pergunta (shared):** todos respondem à mesma questão da rodada, no formato original.
- **Desafio individual (individual):** cada participante recebe uma questão diferente por rodada. O sistema seleciona questões distintas para todos os jogadores durante toda a partida, e a tela de revelação mostra cada pergunta, resposta correta e explicação.

O formato é independente do modo de pontuação (clássico ou bônus por velocidade). A ordem dos participantes continua sendo sorteada/rotacionada entre rodadas. O Duelo Dourado continua usando uma pergunta comum para todos os finalistas.

O modo individual exige perguntas suficientes para `número de jogadores × número de rodadas`. Se o banco selecionado não tiver essa quantidade, o jogo avisa antes de iniciar, sem começar uma partida incompleta.
